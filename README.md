# Oche's Heart Foundation

> **Motto:** Touching Lives. Empowering Citizens. Transforming Society.

A modern, clean, beautiful, and fully responsive website for **Oche's Heart Foundation**, built using **React 19**, **Vite**, **TypeScript**, and **Tailwind CSS**.

---

## 🌟 Core Features & Structure

1. **Header & Navigation (Navbar)**:
   - Official branding logo with animated heart emblem
   - Desktop and Mobile responsive navigation links (*Home, About, Our Focus, Impact, Get Involved, Contact*)
   - Mobile hamburger menu drawer with smooth toggle
   - Sticky glassmorphism header with active scroll indicator
   - Direct "Donate Now" trigger button with gold accent styling

2. **Hero Section**:
   - Primary Motto Headline: *"Touching Lives. Empowering Citizens. Transforming Society."*
   - Subtext: *"A society where every individual enjoys dignity, equal opportunities, responsible leadership, democratic participation and social justice."*
   - High-impact Unsplash community photography with trust badges (*"Grassroots First - 100% Driven"*, *"6 Key Pillars"*)
   - Dual Call-to-Action buttons: **Donate Now** and **Become a Volunteer**

3. **About Section**:
   - **Our Vision** Card: Highlighting dignity, equal opportunities, responsible leadership, democratic participation, and social justice.
   - **Our Mission** Card: Focusing on humanitarian interventions, civic education, democratic participation, credible elections, and good governance advocacy.
   - 3 Guiding Principles: Integrity & Accountability, Compassionate Service, and Civic Empowerment.

4. **Our 6 Core Areas of Focus**:
   - 🛡️ **Humanitarian Services**: Support for widows, orphans, vulnerable families, and disadvantaged communities.
   - ⚖️ **Democracy and Governance**: Promote transparency, accountability, and responsible leadership.
   - 🗳️ **Electoral Education**: Encourage peaceful, credible, free, and fair elections.
   - ✨ **Youth Empowerment**: Build leadership capacity and encourage youth participation in governance.
   - 🎓 **Civic Education**: Educate citizens on their rights, responsibilities, and democratic values.
   - 🏛️ **Community Development**: Support initiatives that improve living conditions and create opportunities.

5. **Impact & Why Us**:
   - **6 Focus Areas**
   - **100% Community Driven**
   - **1 Single Mission**
   - Grassroots metrics and transparency pledge

6. **Get Involved**:
   - 3 Interactive Pathways: **Volunteer**, **Partner With Us**, and **Donate**
   - Interactive modals for submitting volunteer applications and partnership proposals

7. **Contact & Footer**:
   - Functional contact form (*Full Name, Email, Subject, Message*) with submission feedback
   - Direct correspondence: `info@ochesheartfoundation.org`
   - Phone and address details
   - Social media channels: Facebook, X (Twitter), Instagram, LinkedIn, YouTube
   - Back to top smooth scroll
   - Copyright notice: `© 2026 Oche's Heart Foundation`

8. **Interactive Donate Modal**:
   - When any **Donate** button is clicked, an elegant popup modal displays:
     > *"Thank you for your heart to give. Donation details coming soon."*
   - Includes notification signup to alert donors as soon as online channels launch.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ or v20+)
- npm

### Installation & Run

```bash
# Navigate to the project directory
cd oches-heart-foundation

# Install dependencies (if needed)
npm install

# Start the Vite development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
